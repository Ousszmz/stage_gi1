# stage_gi1: Clogging Detection on a Conveyor Belt (Computer Vision)

Internship project (ENSA, GI1) that uses deep learning to classify images of material on a conveyor belt as **good** (normal flow) or **bad** (clogging, *colmatage*).

It has two parts:

1. **`downsampling/`**: selects a small, diverse set of representative frames from a large set of images.
2. **`computer_vision/`**: builds the train/val/test dataset and trains an image classifier.

## 1. Downsampling: representative frame selection

`downsampling/downsampling.ipynb`

Frames taken from video are highly redundant. This notebook keeps only the most representative ones:

1. Loads every image in `INPUT_FOLDER` and resizes it to 224×224.
2. Extracts a 2048-d embedding per image with **ResNet50** (ImageNet weights, frozen, global average pooling).
3. L2-normalises the embeddings.
4. Runs **KMeans** with `k = NUM_SELECTED` clusters.
5. For each cluster, keeps the image closest to the centroid.
6. Copies the selected images to `OUTPUT_FOLDER`.
7. Plots a **UMAP** 2D projection of all images and highlights the selected ones.

Main parameters: `INPUT_FOLDER`, `OUTPUT_FOLDER`, `NUM_SELECTED` (default 20), `IMAGE_SIZE`, `RANDOM_STATE`.

## 2. Classifier: good vs. bad

`computer_vision/train_classifier.ipynb`

### Dataset split
Splits the images in `assets/<class>/` **70 / 15 / 15** into `dataset/train`, `dataset/val` and `dataset/test` (seed 42).

### Model
- **EfficientNetB0** backbone (ImageNet weights) at 224×224 input.
- The first 70% of the backbone layers are frozen and the remaining 30% are fine-tuned.
- Head: GlobalAveragePooling → Dropout(0.3) → Dense(2, softmax, L2 = 0.1).
- Data augmentation: random flip, rotation, zoom, translation, brightness and contrast.

### Training
- Adam optimizer (lr 1e-3), categorical cross-entropy, batch size 16, up to 60 epochs.
- Callbacks:
  - `ModelCheckpoint` saves the best model by `val_accuracy` to `best_model.keras`.
  - `EarlyStopping` (patience 15) restores the best weights.
  - `ReduceLROnPlateau` (factor 0.5, patience 7).

### Results (as recorded in the notebook)
- Training stopped early at epoch 30; the best weights came from epoch 15.
- Test set (54 images): **accuracy 1.00**, precision, recall and F1 1.00 for both classes.

> ⚠️ **Caution about these numbers.** The `dataset/` folder currently in the repo contains images that appear in more than one split: about 38 filenames per class are in both `train/` and `test/`. This most likely comes from running the split cell several times without clearing `dataset/` first. The perfect test score is therefore probably optimistic. To get a reliable score, delete `dataset/`, run the split cell once, and retrain.

### Inference
`classify_image(path)` loads an image, predicts its class, and shows it with the confidence for each class:

```python
model = tf.keras.models.load_model("model_final.keras")
classify_image("path/to/image.jpg")
# Prediction: good
# Confidence: 99.75%
```
